# IPv6 Multi-Network & SLAAC Deployment

## Project Overview

This project demonstrates the configuration and deployment of an IPv6 network using Cisco Packet Tracer. A Cisco 1941 router was used to connect two separate IPv6 LANs, with each LAN containing two PCs connected through a Cisco 2960 switch.

The project focuses on IPv6 addressing, SLAAC (Stateless Address Autoconfiguration), Router Advertisements, IPv6 default gateways, IPv6 routing, and connectivity verification between different IPv6 networks.

## Objectives

- Configure IPv6 addressing on a Cisco router.
- Configure two separate IPv6 networks using /64 prefixes.
- Enable IPv6 routing on the router.
- Configure PCs to obtain IPv6 addresses automatically using SLAAC.
- Verify automatically assigned global and link-local IPv6 addresses.
- Verify IPv6 default gateway configuration.
- Test communication between hosts on different IPv6 networks.
- Verify the router's IPv6 routing table.
- Demonstrate successful end-to-end IPv6 connectivity.

## Network Topology

The network consists of:

- 1 Cisco 1941 Router
- 2 Cisco 2960 Switches
- 4 PCs

Topology:

```text
                    Router0
                   /       \
                G0/0       G0/1
                  /         \
             Switch0       Switch1
              /   \         /   \
            PC0   PC1      PC2   PC3

        IPv6 Network 1     IPv6 Network 2
```

All devices were connected using copper straight-through cables.

## IPv6 Network Design

Two separate /64 IPv6 networks were configured.

### Network 1

IPv6 Prefix:

`2001:DB8:20:1::/64`

Router Gateway:

`2001:DB8:20:1::1/64`

Connected through:

`GigabitEthernet0/0`

Hosts:

- PC0
- PC1

### Network 2

IPv6 Prefix:

`2001:DB8:20:2::/64`

Router Gateway:

`2001:DB8:20:2::1/64`

Connected through:

`GigabitEthernet0/1`

Hosts:

- PC2
- PC3

## Router Configuration

IPv6 routing was enabled on Router0 using:

```text
ipv6 unicast-routing
```

GigabitEthernet0/0 was configured with:

```text
interface gigabitEthernet 0/0
ipv6 address 2001:db8:20:1::1/64
no shutdown
```

GigabitEthernet0/1 was configured with:

```text
interface gigabitEthernet 0/1
ipv6 address 2001:db8:20:2::1/64
no shutdown
```

Both router interfaces were verified as operational with an up/up status.

## SLAAC Configuration

The PCs were configured to use **Auto Config** instead of manually entering IPv6 addresses.

The router's IPv6 configuration allowed it to send Router Advertisements to the connected networks. The PCs then automatically generated their IPv6 addresses using SLAAC.

Each PC received:

- A global IPv6 address
- A link-local IPv6 address
- An IPv6 default gateway
- A `/64` prefix

## Host Addressing

The PCs automatically received addresses from their respective IPv6 prefixes.

### Network 1

PC0 and PC1 received addresses from:

`2001:DB8:20:1::/64`

### Network 2

PC2 and PC3 received addresses from:

`2001:DB8:20:2::/64`

The exact host portions were automatically generated by Packet Tracer through SLAAC.

### PC2 to Router0 G0/1

The PC0-to-PC2 IPv6 ping was successful.

Result:

`0% packet loss`

### PC2 to PC0

The reverse PC2-to-PC0 IPv6 ping was also successful after using the correct automatically assigned IPv6 address.

Result:

These tests confirmed successful two-way IPv6 communication between the two separate networks.

## IPv6 Routing Table Verification

The router's IPv6 routing table was verified using:

```text
show ipv6 route
```

The routing table showed both IPv6 networks as directly connected:

```text
2001:DB8:20:1::/64
```

via:

```text
GigabitEthernet0/0
```

and:

```text
2001:DB8:20:2::/64
```

via:

```text
GigabitEthernet0/1
```

The router also displayed local `/128` routes for its configured interface addresses.

This confirmed that Router0 had routes to both IPv6 networks.

The project was successfully completed.

The following were verified:

- Both router interfaces were up/up.

- All four PCs received IPv6 addresses automatically through SLAAC.

- PC0 successfully communicated with PC2 across the two IPv6 networks.
- PC2 successfully communicated with PC0 across the two IPv6 networks.
